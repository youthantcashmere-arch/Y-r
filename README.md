# Y-r
Build CASHMERE AI FOREX, a beginner-friendly Telegram forex analysis bot using Python.  The bot should:  1. Connect to my existing Telegram bot using the Telegram Bot API. 2. Provide EUR/USD, GBP/USD, and USD/JPY market analysis. 3. Use verified forex price data from an API, configured securely using environment variables. 4. Calculate RSI.
